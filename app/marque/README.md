# Brand assets

Drop your brand logo here (`.svg`, `.png` or `.jpg`). The visual and video agents can reference it by file name in
their compositions (end slide, signature…). Describe how to use it in the art direction, approved from the interface.

Brand fonts go in `app/polices-marque/` (`.woff2` files, named `Family-Style.woff2`). That folder is not versioned:
many font licences forbid redistribution.
